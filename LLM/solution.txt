Представьте, что голосовой робот принимает входящий звонок в аптеку.
Задача робота — понять, какой товар нужен клиенту, и собрать информацию, необходимую для дальнейшего поиска товара в аптечной системе.
Клиент может говорить свободно.
Например:
«Мне нужен Нурофен детский, сироп, большой флакон»
«Есть у вас парацетамол 500 миллиграмм, упаковка на 20 таблеток?»
«Мне что-нибудь от аллергии»

Необходимо использовать LLM, чтобы преобразовать реплику клиента в структурированный JSON.
Желаемый формат:

{
  "product": "Парацетамол",
  "dosage": "500 мг",
  "form": "таблетки",
  "package": "20 таблеток"
}

Если клиент не назвал какое-либо значение, модель должна вернуть null.

Например, для реплики:
«Мне нужен Нурофен детский, сироп»

ожидается результат:
{
  "product": "Нурофен детский",
  "dosage": null,
  "form": "сироп",
  "package": null
}

ЗАДАНИЕ

Напишите промпт для LLM, который:

— получает текст реплики клиента;
— определяет название товара;
— определяет дозировку, если она была названа;
— определяет форму выпуска;
— определяет фасовку или размер упаковки;
— не придумывает отсутствующие данные;
— возвращает только JSON без пояснений и дополнительного текста.
