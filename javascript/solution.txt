ЗАДАЧА 1

После получения данных из API необходимо подготовить текст для робота.
Исходные данные:

const appointment = {
  patientName: "Анна",
  doctor: "Иванов Сергей Петрович",
  specialty: "терапевт",
  date: "2026-10-12",
  time: "15:30"
};

Напишите JavaScript-код, который сформирует строку:
Анна, вы записаны к врачу Иванов Сергей Петрович, терапевт, на 12.10.2026 в 15:30.
Можно использовать обычный JavaScript без дополнительных библиотек.
